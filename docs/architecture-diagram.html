Inspektor Gadget
eBPF-based system inspection. gadgetClient in MCP Bridge queries network traces, DNS lookups, process activity, and system calls directly from the kernel.

Cluster Query Health Tracking
Slow clusters get reduced timeouts on retry. Returns clusterStatus:"unavailable" with HTTP 200 (not 500) to keep dashboard functional. Per-cluster timeout: 15–30s. Aggregated across all healthy clusters.

4. End-to-End Data Flow

Pod Issues — Full Call Chain

Browser loads Dashboard ↓ <PodIssues /> renders ↓ useCachedPodIssues() hook fires ↓ Check IndexedDB/SQLite cache ✓ cached → render instantly (SWR warm) ✗ empty → show skeleton loader ↓ background fetch regardless GET /api/mcp/pods/issues Authorization: Bearer <JWT> ↓ Go Backend JWT validated → user extracted ↓ For each healthy cluster: MCP Bridge.GetPodIssues(cluster) ↓ JSON-RPC over stdio → kubestellar-ops ↓ kubestellar-ops queries Kubernetes API ↓ Returns PodIssue[] { name, ns, cluster, issues[] } ↓ Aggregate (30s timeout per cluster) HTTP 200 OK with JSON results ↓ Frontend Cache → IndexedDB/SQLite React state update → card re-renders isRefreshing=false, isDemoData=false

Real-Time Event Stream

User opens Dashboard ↓ Frontend opens WebSocket ws://host:8080/ws Auth: JWT in query param ↓ Backend WebSocket Hub Client registered in hub map ↓ Background goroutines watch: K8s EventInformer → pod/node/deploy events Falco alerts → security events MCP cluster health → status changes ↓ Event arrives → hub.Broadcast(event) ↓ All connected WS clients receive msg ↓ Frontend EventStream card appends event to list ActiveAlerts card increments badge count ClusterHealth card updates status dot ─── SSE (large dataset) variant ───────────── GET /api/mcp/pods/stream ↓ Backend Sends text/event-stream response Writes chunks as data arrives per cluster ↓ Frontend lib/sseClient.ts consumes ReadableStream Updates card progressively as chunks arrive

5. Authentication & Security

🔐
GitHub OAuth 2.0
State tokens stored in-memory map (not cookies — Safari compatibility). 10-minute TTL. Background cleanup every 5 min. Map pruned when >100 entries. State is single-use.
state paramCSRF safe
🎫
JWT Tokens
Signed with random JWTSecret. 7-day TTL. Silent refresh triggered at 50% lifetime. Contains: user ID, GitHub login, email, avatar URL. Sent as Authorization: Bearer header.
7-dayauto-refresh
🛡️
Middleware Stack
All API routes require valid JWT. Rate limiting prevents abuse. CORS restricts to configured FrontendURL. DOMPurify (dompurify v3) sanitizes user-provided HTML in frontend to prevent XSS.
rate limitCORSXSS safe
